## 1. But/So 프레임워크 심층 분석

### Jenny의 원문 설명
"평범한 서술을 하면 아무도 관심 없어요. 하지만 'but, so'를 쓰면 매 전환마다 시청자의 뇌가 '잠깐, 뭐라고?'라고 반응해요."

### TED Talk 버거 영상에서의 But/So 구조

```
차에서 버거를 만들기 시작했어요 (상황 설정)
BUT 그릴이 충분히 뜨겁지 않아요 (갈등 1)
SO 토마토를 먼저 자르기로 했어요 (해결 시도)
BUT 엄마가 "연기 나잖아!" 소리침 (갈등 2)
SO 서두르기 시작해요 (긴박감)
BUT 줄이 움직이기 시작해요 (시간 압박)
SO 버거가 다 익기 전에 창구에 도착할 위기 (클라이맥스)
```

매 "BUT"마다 새로운 긴장이 생기고, 매 "SO"마다 해결을 향해 움직인다. 이것이 60초 안에 시청자를 붙잡는 구조다.

### 뇌과학 근거: 코르티솔 + 도파민 조합
갈등(but)이 나올 때마다 코르티솔(긴장 호르몬)이 분비된다. 해결(so)을 향해 갈 때마다 도파민(기대 호르몬)이 분비된다. 이 조합이 "몰입(Flow)" 상태를 만든다. 손에 땀을 쥐면서도 끌 수 없는 상태.

### 828 적용 예시

```
두려움에 잠이 안 왔어요 (상황)
BUT 새벽 3시에 눈이 떠졌어요 (갈등)
SO 말씀 카드를 한 장 뽑았어요 (행동)
BUT 뽑은 카드를 보는 순간 손이 떨렸어요 (감정 갈등)
SO 그 말씀을 소리 내어 읽었어요 (해결 시도)
→ [어떤 말씀이었는지는 엔딩에서 공개]
```

## 2. 복선(Foreshadowing) 실전 사례

### Jenny의 원문 설명
"훅에서 가장 과소평가된 것은 복선이에요. 좋은 훅은 스크롤을 멈추게 할 뿐만 아니라 영상 끝까지 보게 만들어요."

### 3가지 복선 유형

**유형 A. 결과 먼저, 원인 나중 (콜드 오프닝)**
할머니가 선물 받고 감동하는 장면으로 시작. 선물이 뭔지는 끝까지 안 보여줌.
→ 시청자: "뭘 줬길래 저렇게 감동하지?" → 끝까지 시청

**유형 B. 메커니즘 제시**
"X의 3가지 이유", "5단계로 만드는 법"
→ 시청자가 진행 상황을 추적 가능. "아직 2번째니까 3번째도 봐야지"

**유형 C. 시각적 복선**
비밀방 영상: 처음에 흐릿하게 완성된 방을 보여줌. 마지막에 선명하게 공개.
→ 시청자: "아까 그 흐릿한 게 뭐였지?" → 끝까지 시청

### 828 복선 패턴 예시
- 콜드 오프닝: 누군가 카드를 보고 눈물 흘리는 장면 (카드 내용 안 보임) → 끝에서 말씀 공개
- 메커니즘: "두려울 때 뽑으면 안 되는 카드 1장이 있어요" → 끝에서 공개
- 시각적: 카드 뒷면만 보여주고, 앞면은 엔딩에서 공개

## 3. 구조와 페이싱 상세 가이드

### 페이싱 그래프 (감정 강도)

```
높음 ┃     ★PEAK
     ┃    / \
     ┃   /   \
     ┃  /     \      ★END
중간 ┃-/-------\----/
     ┃/         \  /
     ┃           \/
낮음 ┃
     ┗━━━━━━━━━━━━━━━━━
     훅  중반   피크  엔딩
     3초  15초  10초  2초
```

### 시간 배분 가이드 (40초 영상 기준)

| 구간 | 시간 | 속도 | 역할 |
|------|------|------|------|
| 훅 | 0~3초 | 빠름 | 시각적 충격 + 복선 |
| 중반 전반 | 4~15초 | 중간 | But/So 시작, 상황 설정 |
| 피크 | 16~28초 | 확 올라감 | 감정 최고조 (갈등, 반전, 웃음) |
| 중반 후반 | 29~35초 | 중간 | 해결을 향한 진행 |
| 엔딩 | 36~40초 | 빠름 | 답 제시 후 즉시 종료 |

### Jenny가 말한 엔딩의 핵심
"답을 말한 직후 바로 컷하세요. 1초라도 더 가면 이탈이 발생해요."
"버거가 기본적으로 날것이었는지가 중요한가요? 전혀요. 시청자는 답을 원했고, 빠르고 간결하게 줬어요."

## 4. Dual Narrative 활용법

### Jenny의 할머니 영상 분석

**내레이션 레이어 (귀로 듣는 것):**
"할머니에게 5달러로 크리스마스 선물을 만들거예요. 먼저 카드를 만들고, 사진을 붙이고..."

**화면 레이어 (눈으로 보는 것):**
할머니와 할아버지가 함께한 옛날 사진 → 할아버지가 돌아가셨다는 맥락을 "말하지 않고 보여줌"

**효과:**
맥락을 말로 설명하면 "할아버지가 돌아가셔서..."라고 길고 무거워짐 → 스크롤
화면으로 보여주면 시청자가 스스로 맥락을 파악 → 더 깊은 감정적 연결

### Dual Narrative가 효과적인 이유
1. 60초 안에 두 배의 정보를 전달 가능
2. 시청자가 능동적으로 맥락을 파악하게 됨 (수동적 시청보다 몰입 증가)
3. 무거운 감정을 직접 말하지 않아도 전달 가능

### 828 Dual Narrative 패턴

**패턴 A. 과정 + 감정**
- 내레이션: 카드를 고르는 과정, 포장하는 법
- 화면: 받는 사람의 힘든 상황 사진, 병원 침대, 혼자 앉아있는 모습

**패턴 B. 정보 + 반응**
- 내레이션: 카드에 적힌 말씀의 의미 설명
- 화면: 카드를 읽는 사람의 실시간 표정 변화

**패턴 C. 질문 + 답의 힌트**
- 내레이션: "두려울 때 어떤 말씀을 읽어야 할까요?"
- 화면: 여러 카드를 넘기는 손, 하나에서 멈춤 (내용은 안 보임)

## 5. 피크엔드 이론 뇌과학 근거

### 이론 배경
노벨 경제학상 수상자 다니엘 카너먼과 바바라 프레드릭슨의 심리학 법칙.

**차가운 물 실험 (1993):**
A: 14도 물에 60초 / B: 14도 물에 60초 + 15도 물에 30초
B가 총 90초로 더 긴데, 대부분 B를 다시 선택. 마지막 느낌이 전체 기억을 결정하기 때문.

**핵심 원리:**
뇌는 60초 영상의 모든 순간을 저장할 여유가 없다. 그래서 "가장 강했던 순간"과 "마지막 순간" 딱 두 장의 사진만 찍어서 저장한다.

### Jenny 영상에서의 피크엔드 패턴

**비밀방 영상 (1.6억 뷰):**
- 피크: 엄마가 "뭐 하는 거야! 집 부수겠다!" → 웃기고 긴장됨
- 엔드: 완성된 방 공개 + 엄마 재등장
- 결과: 평균 시청 횟수 1.4회 (다른 영상 1.2회). 엄마 루프가 닫히면서 재시청 유발

**버거 영상 (4,500만 뷰):**
- 피크: 엄마 "차 태우겠다!" + 연기
- 엔드: "우리가 더 빨리, 더 맛있게 만들었다!"
- 시청자 기억: "엄마 난리친 거 웃겼어" + "결국 이겼다는 게 통쾌했어"

### 피크와 엔드 설계 규칙
1. 피크는 영상 중간~후반에 배치 (60~70% 지점)
2. 엔드는 답 제시 직후 즉시 종료
3. 두 장면에 제작 에너지의 80%를 집중
4. 중간 과정은 But/So로 연결만 하면 충분

## 6. 리텐션 세부 전략

### 호기심 갭 설계법

**퍼즐 비유 (Jenny 원문):**
"영상은 완성된 이미지를 모르는 퍼즐이에요. 시청자는 조각을 맞추며 추측하고, 끝까지 봐야 전체 그림이 완성돼요."

**3단계 호기심 갭 설계:**
1. 아바타가 아는 것 파악 (예: "성경 말씀은 위로가 된다")
2. 아바타가 알고 싶은 것 파악 (예: "어떤 말씀이 가장 위로가 되는가?")
3. 그 갭을 메우는 콘텐츠 제작

### 뇌과학: 정보 갭 이론 (George Loewenstein)
아는 것과 알고 싶은 것 사이의 갭 = 심리적 가려움. 답을 알 때까지 불편함을 느낌. 이 불편함이 영상을 끝까지 보게 만드는 힘.

### 뇌과학: 자이가르닉 효과
미완료 과제를 완료된 과제보다 2배 강하게 기억. 질문 = 미완료 과제. 질문을 던지면 시청자의 뇌가 "이건 아직 안 끝났어"라고 인식하고 답을 찾을 때까지 놓지 못함.

### 진행감 (Progression) 설계
Jenny: "진행감이 없으면 지루해요. 시청자가 끝에 얼마나 가까운지 알아야 해요."

**시각적 진행 표시 방법:**
- 화면에 체크리스트 (✓1 ✓2 □3)
- 카운트다운 타이머
- "3가지 중 2번째" 텍스트 오버레이
- 물리적 진행 (재료가 쌓이는 모습, 카드가 줄어드는 모습)

### 말투 가이드라인

**Jenny 원문:**
"빨리 말하지 말고, 더 간결하게 말하세요. 최소한의 단어로 메시지를 전달하세요."

**나쁜 예:**
"본 영상에서는 칙필레 치킨 샌드위치의 가격 대비 성능을 분석하겠습니다"

**좋은 예:**
"칙필레가 최고래. 근데 6달러? 난 안 내. 1달러로 만들 거야."

**가독성 기준:** 5학년 이하 (readabilityformulas.com). MrBeast Shorts는 1학년 수준.

## 7. 훅(Hook) 설계 공식

### 훅 3단계 (Shock → Expectation → End Goal)

| 단계 | 역할 | 예시 |
|------|------|------|
| Shock | 시각적 충격으로 스크롤 멈춤 | 차 안에서 불 피우는 장면 |
| Expectation | 영상이 뭐에 관한 건지 설명 | "드라이브스루보다 빨리 만들 수 있을까?" |
| End Goal | 끝에서 뭘 알 수 있는지 제시 | 결과가 궁금해서 끝까지 시청 |

### 훅 점검 기준
- 시각적이어야 함 (Visual Action)
- 3초 이내
- 음소거 상태에서도 이해 가능
- 중앙 배치, 프레임에 3개 이상 물체 없음
- 복선 포함

## 8. 추가 참고사항

### 영상 길이별 리텐션 목표
- 30초 미만: 100% 이상 (재시청 필요)
- 35~45초: 90% 이상
- Jenny 평균: 95% 리텐션

### 버킷(Bucket) 전략
같은 틀, 다른 소재의 반복 가능한 포맷. 시리즈지만 순서 무관.
- 메타데이터 연결로 알고리즘이 관련 영상 추천
- 한 영상 본 시청자에게 나머지 자동 추천
- 포맷을 미리 만들지 말 것. 한 영상이 성공하면 그때 버킷으로 확장

### 아웃라이어 전략 (아이디어 발상)
1. 작은 채널(1K 이하) 중 100K+ 조회수 영상 찾기
2. 해당 아이디어 재창조 (자신만의 트위스트 추가)
3. 전통 미디어에서 아이디어 가져오기

### 뇌과학 추가 근거
- 옥시토신 (Paul Zak): 감정적 이야기 → 옥시토신 분비 → 캐릭터에 공감 → 오래 시청
- 도파민 보상 시스템: 답을 기대하는 과정에서 도파민 최대 분비. "곧 답이 나올 것 같아!"가 쾌감
